# Release codenames

Each major release gets a codename, a seagull species name. The codename is
for people to say out loud ("the Miglattius release"); the version number
stays the source of truth.

## Rules

- One codename per release line. Patch releases keep it.
- Codenames are never reused.
- Names are Latin binomials: genus + species, as the species is written.
- Only the version number appears in code, tags and packages. The codename
  is for release notes, the About dialog and conversation.
